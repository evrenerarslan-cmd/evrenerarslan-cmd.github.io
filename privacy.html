Son güncelleme: 30.09.2026

Uygulama Yedekleme, kişisel kullanım için geliştirilmiş bir yedekleme aracıdır.

  • Uygulama, kullanıcının bilgisayarındaki belirli bir klasördeki yedek dosyalarını yalnızca kullanıcının kendi Google Drive hesabına yükler.
  • Google Drive erişimi için yalnızca https://www.googleapis.com/auth/drive.file izni kullanılır; uygulama Drive'daki diğer dosyalara erişemez.
  • Hiçbir veri geliştiriciye, üçüncü kişilere veya başka bir sunucuya gönderilmez, satılmaz, paylaşılmaz.
  • OAuth erişim bilgileri yalnızca kullanıcının kendi bilgisayarında saklanır.
  • Kullanıcı erişimi dilediği zaman https://myaccount.google.com/permissions adresinden iptal edebilir.

Privacy Policy (English)

Uygulama Yedekleme is a personal backup tool. It uploads backup files from the user's own computer only to the user's own Google Drive, using only the drive.file scope (access limited to files the app creates). No data is sent to the developer or any third party, and no data is sold or shared. OAuth credentials are stored only on the user's own computer. Access can be revoked at any time at https://myaccount.google.com/permissions.

Google API kullanımı Google API Services User Data Policy (Limited Use gereksinimleri dahil) ile uyumludur.
